# docs

Documentación obligatoria antes de implementar cada área (spec, sección 21).

| Carpeta | Documento |
|---|---|
| `architecture` | Diagramas de arquitectura y flujos de autenticación y contextos |
| `database` | Diseño detallado: tablas, columnas, claves, índices y restricciones |
| `api` | Especificación detallada de la API |
| `security` | Modelo de amenazas, aislamiento multitenant, privacidad |
| `business-rules` | Membresías, vencimientos, renovaciones, créditos, pagos, reembolsos, suspensiones |
| `design` | Diseño de interfaces y prototipos |
| `testing` | Plan de pruebas |
| `operations` | Guía de despliegue y guía de operación |
| `legal` | Planes, contratos, privacidad, soporte y condiciones de servicio |
| `adr` | Registros de decisiones de arquitectura |
